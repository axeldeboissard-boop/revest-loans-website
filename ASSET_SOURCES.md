# Asset Sources

The operational website assets are stored locally in `client/public/assets` and `client/public/fonts` so the exported project does not depend on Manus-managed storage.

## Revest-owned or user-supplied assets

The Revest logo, property imagery, staff portraits, mission image, signature image, and Revest partner graphic were carried forward from the active Revest Loans website and related user-provided materials. They are included only for operating this repository and should not be reused outside the Revest Loans website without approval.
